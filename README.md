## Как играть

Стрелки / WASD или свайпы: смена полосы, прыжок, кувырок. Пробел / двойной тап: ховерборд. На экране также есть кнопки управления.

**iPhone:** откройте браузерную версию в Safari. Игра использует WebGL 2; нужен современный браузер. Проверка на физическом iPhone не проводилась.

**Android:** скачайте APK, откройте файл и разрешите установку из выбранного источника, если Android попросит. Android 8.0+ и WebView с WebGL 2. Игра полностью включена в APK и работает без сети. Это самостоятельная APK-сборка, не публикация в Google Play. Проверка на физическом Android не проводилась.

Прогресс хранится локально и не синхронизируется между браузером и APK.

## Разработка

Node.js 22.12+ или 24:

```sh
npm install
npm run dev
npm test
npm run build
```

Ключи API не нужны. Готовая браузерная сборка создаётся в `dist/`.

## Сборка Android на Windows

Нужны JDK, Python, официальный Android SDK: platform android-35 и build-tools 35.0.0. После принятия лицензии SDK задайте `JAVA_HOME`, `ANDROID_HOME`, `UU_SIGNING_DIR` (личная папка ключа подписи вне репозитория), затем:

```sh
npm run build
python android/build_apk.py
```

Результат: `android/build/ulan-ude-surfer-1.2.0.apk`. Для обновлений сохраняйте ключ подписи и пароль из `UU_SIGNING_DIR`; никогда не публикуйте их.
